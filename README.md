# 💬 Chat UI Clone

A modern Android Chat UI Clone inspired by WhatsApp and Facebook Messenger. This project demonstrates real-time messaging interfaces, modern chat screens, authentication flows, contact lists, and Material Design 3 UI components.

## 📱 Overview

Chat UI Clone is a mini Android project developed using Android Studio. The application focuses on creating a professional messaging experience with modern UI/UX similar to popular chat applications.

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/pandyaomsanjay/chatui
```

### Open in Android Studio

1. Open Android Studio
2. Select Open Project
3. Choose the project folder

### Firebase Setup

1. Create a Firebase Project
2. Add Android App
3. Download `google-services.json`
4. Place it inside:

```text
app/google-services.json
```

5. Enable:

   * Authentication
   * Firestore Database
   * Firebase Storage

### Run App

Connect an Android device or emulator and click Run.
